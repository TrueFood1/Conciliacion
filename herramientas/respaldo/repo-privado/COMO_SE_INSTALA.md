# Cómo se instala esto (una sola vez)

Los archivos de esta carpeta **pertenecen al repo privado
`TrueFood1/respaldo-truefie`**, no a `Conciliacion`. Están acá nada más para
que se pudieran escribir y revisar antes de que el repo privado existiera.

Cuando estén copiados y empujados al repo privado, **borrá esta carpeta de
`Conciliacion`** (`herramientas/respaldo/repo-privado/`) para que no queden dos
copias que se separen con el tiempo. Esa es la misma lección de las skills.
